Features

Everything you need to run a modern commerce platform

From tenant isolation to payment processing, SabiStart provides the foundation for your marketplace or SaaS commerce platform.

hub

Multi-Tenant Architecture

Isolated PostgreSQL schemas per tenant. Each store gets its own data space while sharing the same application instance.

palette

Theme Marketplace

Tenants can browse, acquire, and activate storefront themes. Customize layouts, colors, and branding without touching code.

payments

Payment Infrastructure

Platform-level payment gateway management with tenant-specific credentials, reconciliation, and dispute tracking.

domain

Custom Domains

Tenants can map custom domains with automatic SSL provisioning. ACME challenge support built in.

analytics

Platform Analytics

Monitor tenant growth, feature adoption, payment health, and operational metrics from a unified dashboard.

cloud_deploy

Multiple Deploy Targets

Deploy to Vercel, Railway, Render, or Defang. Docker-based builds with platform-specific configuration.
